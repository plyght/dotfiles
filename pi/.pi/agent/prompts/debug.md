Debug the issue described below. Follow this process:

1. **Reproduce** — Understand the exact failure (error message, stack trace, unexpected behavior)
2. **Hypothesize** — List 2-3 most likely root causes
3. **Investigate** — Read relevant code, check logs, trace the execution path
4. **Isolate** — Narrow down to the exact line/condition causing the issue
5. **Fix** — Apply the minimal correct fix
6. **Verify** — Run tests or demonstrate the fix works
